PROJECT 01

Biology 3D Game

An educational 3D Game designed to make learning biology more interactive

TECHNOLOGY

Unity

TYPE

Educational Game

STATUS

In Development

THE IDEA

Making biology more interactive.

I pitched the idea of implementing interactive learning through 3D games to my biology teacher and got approval to work on this project.

WHAT I'M BUILDING

The project uses a 3D environment to represent biological concepts and allow users to interact with them rather than simply reading about them.
